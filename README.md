
# Employee Management System 👨‍💼

A simple and interactive Employee Management System developed using HTML, CSS, and JavaScript. It helps users manage employee information through an easy-to-use interface.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Local Storage

## Features
- Add new employee records
- View employee details
- Search employees by name or designation
- Edit employee information
- Delete employee records
- Automatically save records using browser Local Storage
- Responsive user interface

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start managing employee records.
